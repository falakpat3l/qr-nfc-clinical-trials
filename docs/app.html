Capture app

Record a dosing event by scanning it, instead of writing it down and typing it up later.

Everything stays in this browser. Nothing is uploaded, and there is no server to upload it to. · Source

Generate a label

Fill in the event, print the code, attach it to the cage or the dosing sheet. Scanning it later writes the whole record in one action.

The code carries the fields above as plain text, not a URL. It resolves without a network connection and points at no server.

Scan a label

Point the camera at a code. Each new code is logged once, with the time it was read.

The camera needs a secure context. This works on localhost and over HTTPS. Video never leaves the page: frames are decoded here and discarded.

NFC tags

A tag has to be physically tapped, so a reading is much harder to fabricate than a photographed code. That is the one thing NFC buys you over QR, and it costs about 3 seconds per event and the price of the tag.

Time yourself

Rather than trusting my numbers, measure your own. Pick a method, start the clock, and press Captured once per recorded observation. The gap between presses is one capture event.

Press Start as you reach the first subject, not before: the first interval is measured from that press, so any walking you do in between lands inside it.
